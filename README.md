# 5G Toolbox 学习笔记

MATLAB 5G Toolbox 的学习记录与仿真代码。目标不是把工具箱的函数过一遍，而是能独立完成链路级仿真、改源码搭自定义模块、产出可用于论文的性能曲线。

覆盖两条主线：**物理信道**（协议层：PDSCH/PUSCH/PDCCH/PUCCH/PRACH/SSB 的信号结构）和**传播信道**（物理层：多径衰落、大尺度路损、小尺度 TDL/CDL 建模、信道估计与均衡），并在端到端处打通。

## 环境要求

- MATLAB **R2022b 或更新**。5G Toolbox 的 API 在 R2021a 有过一次大规模改版（上下行参数收进 `nrULSCHConfig` / `nrDLSCHConfig` 和 `nrPUSCHConfig` / `nrPDSCHConfig` 这类配置对象，加扰调制预编码由 `nrPDSCH` / `nrPUSCH` 一步完成），网上大量教程仍是旧写法，照抄会报函数不存在。
- 必需工具箱：5G Toolbox、Communications Toolbox
- 常用可选：DSP System Toolbox（滤波与重采样）、Phased Array System Toolbox（多天线与波束赋形）、RF Toolbox（射频损伤建模）

检查本机版本：

```matlab
ver('nr')      % 5G Toolbox
ver('comm')    % Communications Toolbox
```

## 脚本怎么跑

六个脚本相互独立，可以单独运行，也可以按顺序跑。每个都是自包含的（自己配置载波、自己生成数据），直接 F5 即可，不需要预先设置工作区。

输出形式统一：控制台打印关键数值 + 弹出图窗画可视化。每个脚本末尾都有"验收自查"清单，用来确认自己真的理解了而不只是跑通了。

**关于版本敏感处**：脚本里凡是属性名或函数签名可能随版本变化的地方，都写了 `doc` 提示。遇到报错先看提示，用 `doc <函数名>` 核对自己的版本，不要直接搜解决方案（网上答案多数对应旧版）。

## 理论参考

工具箱本质上是 3GPP 规范的可执行实现，读代码时对照规范比看二手教程效率高。

**物理信道**看 38 系列：
- **TS 38.211** 物理信道与调制（帧结构、numerology、参考信号序列、OFDM 基带信号）
- **TS 38.212** 复用与信道编码（LDPC、Polar、CRC、速率匹配）
- **TS 38.213 / 38.214** 物理层过程与数据传输（功率控制、链路自适应、MCS 表、TBS）

**传播信道**看：
- **TR 38.901** 信道模型（大尺度路损、阴影衰落、TDL/CDL 小尺度模型）
- **TS 38.101 / 38.104** 射频指标

`docs/channel-theory-notes.md` 里有完整的推导，包括 WSSUS 假设、相干带宽/相干时间的由来、OFDM 对角化的三个条件、LS/MMSE 估计器推导、ZF/MMSE 均衡器推导、3GPP 信道模型结构、路损公式推导。

## 仿真注意事项

做科研仿真和"跑通官方示例"是两回事，几个容易踩的坑：

**样本量**。BLER 低于 1e-3 时每点至少几千个传输块，否则曲线抖动会掩盖真实的性能差异。`ch06` 为了跑得快只用了 60 次，所以低 BLER 段会抖——这本身就是个反面教材，真实仿真要加大到几千次。

**信道实现数**。CDL/TDL 是随机信道，每个信噪比点要在多个信道实现上平均，否则结果不具统计意义。

**采样率对齐**。`nrCDLChannel` / `nrTDLChannel` 的 `SampleRate` 必须与实际波形采样率一致，否则信道模型的行为没有物理意义。`ch05` 里演示了怎么从载波配置反推正确的采样率。

**可复现性**。固定随机种子（`rng`），记录全部参数，把配置对象序列化保存。结果无法复现是审稿意见里最常见的批评之一。

**相干量的系数要声明**。`docs/channel-theory-notes.md` 里说明了相干带宽和相干时间在不同判据下的系数差异——尤其是流传很广的 `0.423/f_d` 其实不是 `J0=0.5` 的结果。写论文时要说清用的哪个判据，否则和别人对不上。
