# 5G Toolbox 学习笔记

MATLAB 5G Toolbox 的学习记录与仿真代码。目标不是把工具箱的函数过一遍，而是能独立完成链路级仿真、改源码搭自定义模块、产出可用于论文的性能曲线。

## 目录结构

```
.
├── docs/                  学习笔记与路线文档
│   └── 5g-toolbox-learning-path.md    系统学习路线（四阶段）
├── code/                  MATLAB 脚本与仿真代码
└── README.md
```

后续按阶段往 `code/` 下加脚本，建议按 `stage1_xxx/`、`stage2_xxx/` 分目录，每个目录配一个 `README.md` 说明该脚本在验证什么、怎么跑、预期输出是什么。

## 环境要求

- MATLAB **R2022b 或更新**。5G Toolbox 的 API 在 R2021a 有过一次大规模改版（上下行参数收进 `nrULSCHConfig` / `nrDLSCHConfig` 和 `nrPUSCHConfig` / `nrPDSCHConfig` 这类配置对象，加扰调制预编码由 `nrPDSCH` / `nrPUSCH` 一步完成），网上大量教程仍是旧写法，照抄会报函数不存在。
- 必需工具箱：5G Toolbox、Communications Toolbox
- 常用可选：DSP System Toolbox（滤波与重采样）、Phased Array System Toolbox（多天线与波束赋形）、RF Toolbox（射频损伤建模）

检查本机版本：

```matlab
ver('nr')      % 5G Toolbox
ver('comm')    % Communications Toolbox
```

## 规范参考

工具箱本质上是 3GPP 38 系列规范的可执行实现，读代码时对照规范比看二手教程效率高。主线是两本：

- **TS 38.211** —— 物理信道与调制。帧结构、numerology、参考信号序列、OFDM 基带信号生成。回答"信号长什么样"。
- **TS 38.212** —— 复用与信道编码。LDPC、Polar、CRC、速率匹配、交织。回答"比特怎么变成码字"。

辅助：TS 38.213（物理层过程，功率控制/链路自适应/波束管理）、TS 38.214（数据传输，MCS 表/TBS/资源分配/CSI）、TS 38.101 与 38.104（射频指标）。

`docs/5g-toolbox-learning-path.md` 附录 C 有一张「理论概念 → 规范章节 → 工具箱函数」的对照表。

## 学习进度

按路线文档的四个阶段推进，完成后勾上：

- [ ] **阶段一：物理层地基** —— numerology 与帧结构、OFDM 波形生成、参考信号分类
- [ ] **阶段二：上下行业务信道** —— PDSCH/PUSCH 从比特到波形、TBS 计算、变换预编码、控制信道与 SSB
- [ ] **阶段三：接收端与端到端仿真** —— 信道估计与均衡、LDPC 解码、CDL/TDL 信道模型、BLER 与吞吐量曲线
- [ ] **阶段四：按课题方向深入** —— 大规模 MIMO / URLLC / 毫米波相位噪声 / AI 辅助空口（择一）

## 笔记约定

每学完一个模块，在同一处记三样东西，三样对上了才算真懂：

1. **规范位置** —— 哪本规范的第几节
2. **工具箱入口** —— 主要函数或配置对象
3. **可运行的验证例子** —— 最短能跑通、能看到预期输出的脚本，放进 `code/`

## 仿真注意事项

做科研仿真和"跑通官方示例"是两回事，几点容易踩的坑：

- **版本差异**：函数报错先查 `ver('nr')` 和本机 `doc`，不要盲目搜解决方案，网上答案多半对应旧版 API。
- **样本量**：BLER 低于 1e-3 时每点至少几千个传输块，否则曲线抖动会掩盖真实的性能差异。
- **可复现性**：固定随机种子（`rng`），记录全部参数，把配置对象序列化保存。结果无法复现是审稿意见里最常见的批评。
- **采样率对齐**：`nrCDLChannel` 的 `SampleRate` 必须与实际波形采样率一致，否则信道模型的行为没有物理意义。

## 参考

- 官方文档：MATLAB 中执行 `doc 5G Toolbox`，Examples 一栏的所有例子都可直接以实时脚本打开逐段执行，是最快的学习材料。
- 建议从 `NR PDSCH Throughput` 这个示例入手，它把发送、信道、接收、误块率统计全串起来了。
